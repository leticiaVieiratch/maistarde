## 📌 Apresentação Geral

Este repositório reúne o conjunto completo de projetos práticos, laboratórios de código e relatórios técnicos desenvolvidos para a disciplina de **Frameworks Front-End**, ministrada pelo **Prof. Me. Deivison S. Takatu** no **SENAI**.

O conteúdo percorre toda a trilha pedagógica da formação, partindo dos fundamentos essenciais de arquitetura web e manipulação de DOM nativo com JavaScript puro (Vanilla JS), passando pela estilização moderna com Box Model e Tailwind CSS, governança de projetos ágeis (Scrum/Kanban), desenvolvimento modular com componentes em **React 18**, gerenciamento avançado de estado e rotas SPA com **React Router DOM**, até a criação, persistência, teste automatizado com Postman e publicação em nuvem de **APIs RESTful com Node.js e Express**.

## 🔍 Resumo Detalhado por Módulo

### 📁 [01-Apresentacao-e-Configuracao-Ambiente/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/01-Apresentacao-e-Configuracao-Ambiente/)
- **Aplicação Prática (`atividade-01-vanillajs`):** Sistema completo de notas com Vanilla JS, CSS3 Moderno (Custom Properties, Flexbox, Dark/Light Mode), persistência no `localStorage`, filtragem dinâmica e painel de métricas.
- **Relatório Técnico Acadêmico (`atividade-02-documentacao`):** Documento em conformidade com as normas ABNT contendo resumo executivo da Aula 01 e análise comparativa de mais de 5 páginas entre os principais frameworks do mercado (*React, Angular, Vue.js, Svelte*).

### 📁 [02-Frameworks-CSS/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/02-Frameworks-CSS/)
- **Exercício Box Model & Flexbox (`atividade-01-box-model-flexbox`):** Interface didática com **20 elementos HTML identificados** (`elem-01` a `elem-20`), demonstrando explicitamente as propriedades do Box Model (*Content, Padding, Border, Margin, Box-Sizing*) e mais de 20 regras de Flexbox (*flex-direction, justify-content, align-items, flex-wrap, order*).
- **Dashboard Tailwind CSS (`atividade-02-tailwind`):** *DevPulse Analytics Dashboard*, interface de painel responsiva e moderna com classes utilitárias do Tailwind CSS, gráficos e tabela com documento de mapeamento de 54 classes Tailwind para CSS nativo.

### 📁 [03-Gestao-de-Projetos-FrontEnd/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/03-Gestao-de-Projetos-FrontEnd/)
- **Manual de Governança Ágil:** Guia completo cobrindo Visão do Produto, Personas, Requisitos Funcionais e Não-Funcionais, Histórias de Usuário no formato BDD/Gherkin (*Given-When-Then*), priorização MoSCoW, pontuação Fibonacci, planejamento de 3 Sprints, DoR, DoD e convenções de commit (Git Flow & Conventional Commits).
- **Kanban Board Interativo (`kanban-board`):** Aplicação interativa com HTML5 Drag-and-Drop, limites de WIP (*Work in Progress*), avisos de gargalo, filtros por responsável/prioridade e persistência de cartões no `localStorage`.

### 📁 [04-Fundamentos-React/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/04-Fundamentos-React/)
- **Aplicação Didática dos Pilares do React:** Interface que leciona interativamente os 6 conceitos nucleares: JSX, Componentes Funcionais, Props, Virtual DOM & Reconciliação, Listas com Chaves Únicas (*Keys*) e Renderização Condicional.
- **Dualidade de Execução:** Executável direto via navegador (*zero-setup*) e projeto modular estruturado para build com **Vite**.

### 📁 [05-React-Avancado-Hooks-e-Rotas/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/05-React-Avancado-Hooks-e-Rotas/)
- **DevPulse Notes & API Hub:** SPA em **React 18** com navegação declarativa usando **React Router DOM 6** (`BrowserRouter`/`HashRouter`, `<Routes>`, `<Route>`, `<Link>`, `useParams()`, `useNavigate()`).
- **Hooks e Formulários Controlados:** Implementação de `useState`, formulários controlados com `event.preventDefault()`, validações síncronas de inputs, e `useEffect` com array de dependências e função de limpeza (*cleanup* via `AbortController`).
- **Consumo de APIs Assíncronas:** Módulo com requisições `fetch` (`GET` e `POST`), tratamento de erros com `try...catch...finally`, checagem de `response.ok` e estados visuais de carregamento (*loading spinners*).

### 📁 [06-Criando-e-Consumindo-APIs/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/06-Criando-e-Consumindo-APIs/)
- **Análise Técnica de 10 Projetos do GitHub:** Relatório detalhado investigando repositórios reais que utilizam APIs no front-end (GitHub API, Spotify OAuth2 PKCE, TMDB, OpenWeather, PokéAPI, CoinGecko, Stripe, NASA, Unsplash, Rick and Morty).
- **Backend RESTful em Express:** Servidor Node.js com persistência em `data.json` através do módulo `fs/promises`, middlewares `cors` e `express.json()`, logger de requisições e endpoints CRUD completos para a entidade `/api/notes`.
- **Coleção Postman Automatizada:** Arquivo exportável no padrão Postman Schema v2.1.0 com 11 requisições, variáveis de ambiente encadeadas e scripts de asserção em Chai (`pm.test`).
- **Guia de Deploy em Produção:** Passo a passo detalhado de publicação do backend no **Render.com** (com porta dinâmica `process.env.PORT`) e do frontend no **Vercel** (com *SPA rewrites* e resolução de CORS).

### 📁 [07-Frameworks-CSS/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/)
- **Atividade 01 (Slide 33):** Projeto HTML/CSS externo com 20 elementos estilizados em todas as propriedades de Box Model (*Content, Padding, Border, Margin*) e mais de 20 propriedades Flexbox manipuladas responsivamente.
- **Atividade 02 (Slide 46):** DevPulse Analytics Dashboard utilizando mais de 54 classes distintas do Tailwind CSS e documentação técnica completa em Markdown.

### 📁 [08-Projeto-React/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/08-Projeto-React/)
- **Atividade Prática (Slide 83):** Aplicação interativa em React 18 abordando os fundamentos essenciais da Aula 08: sintaxe JSX com expressões dinâmicas, hierarquia de componentes modulares, fluxo unidirecional de props, modelo conceitual do Virtual DOM com reconciliação, renderização de listas com identificadores estáveis (`keys`) e renderização condicional.

### 📁 [09-Projeto-React-02/](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/09-Projeto-React-02/)
- **Atividade Prática (Slide 41):** Aplicação SPA completa cobrindo os conceitos avançados da Aula 09: gerenciamento de estado reativo com `useState`, formulários 100% controlados com validações síncronas e `e.preventDefault()`, efeitos colaterais e sincronização com `useEffect` (incluindo rotina de limpeza com `AbortController`), consumo assíncrono de APIs REST externas (`fetch` com GET/POST e estados de carregamento/erro) e roteamento declarativo com `react-router-dom` (`BrowserRouter`/`HashRouter`, `<Routes>`, `<Route>`, `<Link>`, `useParams()`, `useNavigate()`).

   - [Aula 07 • Tailwind Dashboard (Atividade 02)](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-02-tailwind/index.html)
   - [Aula 08 • Catálogo de Fundamentos React](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/08-Projeto-React/index.html)
   - [Aula 09 • DevPulse Notes SPA & APIs](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/09-Projeto-React-02/index.html)

### Opção 2: Executando o Servidor de Backend Express (Atividade 06)
```bash
# 1. Acessar o diretório da API
cd "06-Criando-e-Consumindo-APIs/atividade-02-api-express-crud"

# 2. Instalar as dependências
npm install

# 3. Rodar a suíte de testes de integração automatizados
npm test

# 4. Iniciar o servidor
npm start
# O servidor estará disponível em http://localhost:3001
```

### Opção 3: Executando os Projetos React com Vite (Aulas 08 e 09)
```bash
# Para a Aula 09 (ou Aula 08):
cd "09-Projeto-React-02"
# ou: cd "08-Projeto-React"

# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```

## 🛠️ Tecnologias e Ferramentas Empregadas

- **Linguagens:** HTML5 semântico, CSS3 Moderno, JavaScript ES6+ (Async/Await, Promises, Destructuring, Modules);
- **Bibliotecas & Frameworks Front-End:** React 18, React Router DOM 6, Tailwind CSS;
- **Back-End & APIs:** Node.js, Express.js, CORS, FS/Promises, RESTful API Design;
- **Ferramentas de Teste e Qualidade:** Postman Collection v2.1.0, Newman CLI, Test scripts nativos;
- **Plataformas de Deploy:** Vercel (Edge CDN) e Render.com (Web Services Node.js);
- **Metodologias:** Scrum, Kanban, User Stories (Gherkin/BDD), MoSCoW, Conventional Commits.
