### 🔹 Atividade 01: Box Model & Flexbox (Slide 33)

**Enunciado Oficial:**
1. Crie um projeto e utilize os arquivos `index.html` e `style.css`, incluindo o CSS de forma Externa ao HTML, através da tag `<link>`.
2. Adicione 20 elementos e atribua valores em todas as propriedades de **Content**, **Padding**, **Border** e **Margin**.
3. Em seguida, adicione 20 propriedades de **Flexbox** para manipular os elementos e organizá-los de forma responsiva.

📂 **Pasta da Atividade:** [`atividade-01-box-model-flexbox/`](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-01-box-model-flexbox/)  
🌐 **Execução Instantânea:** [Abrir index.html no Navegador](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-01-box-model-flexbox/index.html)  
📄 **Estilo Externo:** [`style.css`](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-01-box-model-flexbox/style.css)

**Destaques da Implementação:**
- 20 elementos semanticamente identificados (`elem-01` a `elem-20`).
- Todas as 4 camadas do Box Model aplicadas e auditadas explicitamente em cada elemento.
- Mais de 20 regras e propriedades Flexbox demonstradas na prática (`display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`, `flex-grow`, `flex-shrink`, `flex-basis`, `order`, etc.).
- Totalmente responsivo com Mobile First e Media Queries.

### 🔹 Atividade 02: Tailwind CSS Utility-First (Slide 46)

**Enunciado Oficial:**
1. Crie um projeto que utilize pelo menos **30 classes diferentes do Tailwind CSS**. As classes devem ser utilizadas para definir elementos como cores, tipografia, espaçamentos, dimensões, bordas, posicionamento, flexbox, grid e responsividade.
2. Organize a entrega em um repositório, e documente através de um markdown, contendo prints do código, da aplicação em funcionamento, uma lista das classes utilizadas com suas respectivas funções e o link para o projeto desenvolvido.

📂 **Pasta da Atividade:** [`atividade-02-tailwind/`](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-02-tailwind/)  
🌐 **Execução Instantânea:** [Abrir Tailwind Dashboard no Navegador](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-02-tailwind/index.html)  
📖 **Documentação Técnica e Mapeamento:** [DOCUMENTACAO_TAILWIND.md](file:///c:/Users/Letícia%20Vieira/Desktop/DevisonProjeto/07-Frameworks-CSS/atividade-02-tailwind/DOCUMENTACAO_TAILWIND.md)

**Destaques da Implementação:**
- Dashboard administrativo completo (*DevPulse Analytics*).
- Mais de 54 classes utilitárias distintas do Tailwind CSS categorizadas.
- Tabela de mapeamento completa de cada classe utilitária para o CSS nativo correspondente.
- Suporte a modo escuro/claro, grid responsivo (`grid-cols-1 md:grid-cols-2 lg:grid-cols-4`), flexbox, badges, tabelas e cards.
